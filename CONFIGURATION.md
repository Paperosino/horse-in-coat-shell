# Настройки Hyprstack

Пути ниже используют `~/.config`; если задан XDG_CONFIG_HOME, используются его
подкаталоги. Настройки сохраняются отдельно от установленного приложения.

| Файл | Назначение |
| --- | --- |
| `hyprstack/shell.json` | Панели, темы интерфейса, уведомления, погода, фон и анимации |
| `hyprstack/layouts.json` | Режим размещения: scrolling или stacking |
| `hyprstack/workspaces.json` | Количество рабочих столов и распределение по мониторам |
| `hyprstack/effects.json` | Размытие и графические эффекты |
| `hyprstack/tiling.json` | Рамка рабочего стола, отступы, граница фокуса и автопрокрутка |
| `hyprstack/hypr-vars.lua` | Программы, горячие клавиши, оформление Hyprland |
| `hyprstack/monitors.lua` | Собственные настройки экранов; в поставке файл пустой |
| `hyprstack/local.lua` | Дополнительные настройки Hyprland |
| `hyprstack/hypr-user.lua` | Подключение Hyprstack и пользовательских файлов |
| `hyprstack/monitors/<имя экрана>/shell.json` | Настройки оболочки для отдельного монитора |

Изменяйте параметры оболочки через интерфейс настроек. При редактировании JSON
вручную сохраняйте корректный JSON без комментариев и лишних запятых.
`hypr-vars.lua` должен возвращать таблицу; остальные файлы Lua могут вызывать
`hl.config`, `hl.monitor` и другие функции Hyprland 0.56.

По умолчанию используются предпочтительный режим монитора, автоматическое
расположение и масштаб, а также раскладка клавиатуры us. HDR, VRR,
заданные имена/частоты мониторов и параметры конкретного GPU не включены.
Настройте экраны и раскладку под свою систему в `monitors.lua` и `local.lua`.

Личные изображения не включены в поставку. Пока обои не выбраны, рабочий стол
использует однотонный фон текущей темы. Выберите изображение через
**Обои и оформление → Обои → Обзор**; каталог по умолчанию — `Wallpapers`
в системной папке изображений. Динамическая палитра требует выбранных обоев.

Ползунок яркости использует DDC/CI для внешних мониторов и системную подсветку
для встроенного экрана. Цветовой режим и параметры HDR задаются пользователем
в локальной конфигурации Hyprland.

Пример `local.lua`:

```lua
hl.config({ input = { kb_layout = "us,ru", kb_options = "grp:alt_shift_toggle" } })
```

## Горячие клавиши

`Super` — клавиша Windows/Meta. Основные действия:

| Сочетание | Действие |
| --- | --- |
| Super | Основная панель с обзором и запуском приложений |
| Super + D | Запуск приложений |
| Super + O | Обзор окон и рабочих столов |
| Super + Ctrl + Shift + M | Переключение scrolling / stacking |
| Super + H / L | Предыдущая / следующая колонка; на краю — окно на другом мониторе |
| Super + J / K | Следующий / предыдущий рабочий стол |
| Super + Ctrl + F | Половина / полная ширина колонки |
| Super + Shift + стрелка | Перенос окна на соседний монитор |
| Super + Enter | Терминал kitty |
| Super + W | Браузер firefox |
| Super + E | Файловый менеджер через xdg-open |
| Super + Q | Закрыть активное окно |
| Super + F | Полный экран |
| Super + Alt + Space | Переключить окно между тайлингом и плавающим состоянием |
| Alt + Tab / Alt + Shift + Tab | В stacking — выбор окна, вперёд / назад |
| Super + N | Центр уведомлений |
| Super + V | История буфера обмена |
| Super + Period | Выбор emoji; копирование, ввод при наличии wtype |
| Ctrl + Super + L | Блокировка |
| Ctrl + Alt + Delete | Меню сеанса |
| Super + Alt + K | Показать/скрыть панели |
| Print | Снимок текущего монитора |
| Super + Shift + S | Замороженный выбор области снимка |
| Ctrl + Alt + R | Начать/остановить запись экрана |
| Super + Alt + R | Запись со звуком |

Полный список переменных находится в `shell/assets/hyprland/config/variables.lua`.
В настройках **Сочетания клавиш** доступен список действующих сочетаний
Hyprland с поиском по действию и клавишам. Он учитывает `hypr-vars.lua`,
`local.lua` и пользовательские привязки с описанием. После перечитывания
конфигурации список обновляется автоматически; кнопка «Обновить» обновляет его
вручную. Для своих привязок укажите `description` в третьем аргументе `hl.bind`.
Переопределите нужные значения в `hyprstack/hypr-vars.lua`, например
`terminal = "foot"`, `browser = "chromium"`. Настройки самой оболочки для программ
находятся в `general.apps` файла `shell.json`.

На краю ряда Super+H/L переходит на другой монитор с окном на его текущем
рабочем столе, только если тот расположен в выбранном направлении.
За внешним краем группы экранов фокус остаётся на текущем окне; переходов
по кругу нет. Монитор с пустым текущим рабочим столом пропускается.

Новые плавающие диалоги, включая подтверждения XWayland, открываются по центру
доступной области экрана основного окна с учётом панели и рамки. После открытия
их можно свободно перемещать. Контекстные меню сохраняют положение возле
указателя. Общий заголовок Telegram/AyuGram не включает закрепление PiP:
WebApp открывается как обычное плавающее окно.
Отдельный процесс WebApp определяется по аргументу `-webviewhelper` и связывается
с запустившим его Telegram, поэтому название бота и текущий активный монитор
не влияют на размещение окна.

В тайловом режиме **Super+Alt+Space** делает активное окно плавающим; повторное
нажатие возвращает его в колонку. То же действие доступно в меню окна.
Положение и размер плавающего окна сохраняются при переходах между режимами.

В stacking **Alt+Tab** открывает переключатель с миниатюрами, значками и
названиями окон. Он показывает последние использованные окна, включая свёрнутые.
Удерживайте Alt и нажимайте Tab для выбора; **Shift+Tab** выбирает в обратном
порядке. Отпускание Alt или **Enter** активирует выбранное окно и восстанавливает
его, если оно свёрнуто. **Esc** отменяет выбор; доступны также стрелки и мышь.

## Язык и регион

В **Язык и регион → Язык интерфейса** выберите **Русский**, **English** или
**Язык системы**. По умолчанию используется русский. Перевод меню, настроек,
подсказок и дат меняется сразу. Команды Hyprstack используют этот же выбор языка;
названия команд и поля JSON остаются постоянными.

В `shell.json` параметр `general.language` принимает `"ru_RU"`, `"en_US"` или
пустую строку для языка системы. Единицы измерения и формат часов настраиваются
отдельно. Для отдельного запуска CLI можно задать `HYPRSTACK_LANGUAGE=en_US`.

## Панель и масштаб

В настройках **Панели → Панель задач → Видимость элементов** выберите **Все экраны**
для общих настроек или имя конкретного экрана. Логотип, рабочие столы, заголовок,
трей, часы, индикаторы, уведомления, меню питания и кнопки приложений в stacking
можно включать независимо для каждого монитора. Изменения для отдельного экрана
сохраняются в его `monitors/<имя>/shell.json` и имеют приоритет над общими.

Заголовок в scrolling закреплён в центре панели. Дата, секунды и количество
значков справа влияют на доступную длину текста; при нехватке места он сокращается.
Если выключить **Показывать пустые пространства**, остаются все рабочие столы от первого до
последнего занятого или текущего. Пустые столы внутри этого диапазона сохраняются.

В **Обои и оформление → Масштаб интерфейса** настройка **Масштаб оболочки** меняет размер
панелей, меню, текста, значков, рамки рабочего стола и виджетов от 50 до 200%.
Изменение применяется сразу. В `shell.json` это `appearance.scale`: например,
`1.25` соответствует 125%. Настройка сохраняется отдельно от базовых размеров
и существующих параметров шрифтов, отступов и часов.

В **Обои и оформление → Переключение окон при наведении в тайловом режиме**
можно настроить автоматическую смену фокуса при наведении. По умолчанию она
включена: наведите курсор на окно, чтобы передать ему фокус без клика.
В stacking фокус по-прежнему меняется по нажатию.

Если отключить эту настройку, наведение на частично скрытое соседнее окно показывает небольшую
кнопку со стрелкой, плавно вытекающую из рамки у соответствующего края экрана,
в стиле меню панели задач. Области вызова звука и яркости остаются доступными:
стрелка появляется в ближайшем свободном месте и уступает открытым панелям.
Нажатие кнопки переводит
фокус на это окно и прокручивает его в кадр. Для полностью скрытого соседнего
окна наведите указатель к краю экрана. Обычные клики и горячие клавиши продолжают
переключать окна. В `tiling.json` настройка называется `focusOnHover` и по
умолчанию равна `true`; изменения применяются сразу. Если в существующем
файле явно сохранено `false`, включите настройку в интерфейсе.

В **Обои и оформление → Прокрутка средней кнопкой мыши** можно отключить или включить
автопрокрутку средней кнопкой мыши. Удержите колёсико около 0,2 секунды и отпустите:
курсор сменится на стрелки, движение от точки нажатия задаёт направление и
скорость прокрутки. Чем дальше курсор, тем выше скорость. Возврат к точке нажатия
приостанавливает прокрутку; **Esc**, другой клик или обычное вращение колёсика
останавливает её. Можно также удерживать колёсико при движении и отпустить для
остановки. Поддерживаются вертикальная и горизонтальная прокрутка в приложениях,
которые обрабатывают обычные события прокрутки.

Короткий средний клик сохраняет обычное действие приложения: закрытие вкладки,
открытие ссылки или вставку. **Ctrl + средняя кнопка** всегда передаётся приложению.
Меню, панель, рабочий стол и экран блокировки сохраняют свои действия.
В `tiling.json` настройка называется `autoscroll`.
В простое и при неподвижном курсоре в точке нажатия таймер прокрутки не работает;
при смене фокуса, закрытии окна и блокировке прокрутка прекращается.
Скорость нарастает плавно, частота событий следует частоте монитора:
для 200 Гц интервал составляет 5 мс. Фактическая частота отрисовки зависит
также от приложения и его графического ускорения.

В **Обои и оформление → Отступы между окнами** доступны численные значения внутренних
отступов `gapsIn` и внешних `gapsOut`, от 0 до 100 px. Внутренний отступ задаётся
с каждой стороны окна. Внешний отступ одинаков для одного и нескольких окон;
он не меняется автоматически при расширении колонки. **Win+G** выключает
отступы и возвращает сохранённые значения при повторном нажатии.

В **Обои и оформление → Тени** можно отдельно включать тени окон и интерфейса,
задавать размер от 0 до 60 px и интенсивность от 0 до 100%. Параметры сохраняются
в `effects.json` как `windowShadows`, `uiShadows`, `shadowSize`, `shadowOpacity`.
Тени нейтрального чёрного цвета; их размер и интенсивность общие для всех окон
и не меняются при переключении фокуса. Соприкасающиеся
тайлы без отступов не создают тень на общих границах. Отключение теней интерфейса
отключает и соответствующие графические слои. Рамка неактивного окна имеет
нейтральный серый цвет, который следует цветовой схеме; в scrolling толщина
рамки общая для активных и неактивных окон. В stacking рамки окон скрыты.
Цвет активной рамки выбирается отдельно в **Цвет рамки окна**: доступны
акцент и основные оттенки темы: обычно 8–10 вариантов без повторов.
Ранее выбранный оттенок дополнительно остаётся доступен в списке.
Полная исходная палитра и все 16 цветов ANSI сохраняются внутри темы. Исходные цвета
сохраняются без изменения; корректировка контраста применяется к ролям интерфейса.
Одинаковые цвета объединены в один
вариант; сохранённая роль цвета остаётся прежней. `focusBorderColor` в `tiling.json`
хранит роль цвета; при смене темы или светлого/тёмного режима рамка использует
соответствующий цвет новой палитры. Если именованного оттенка в новой теме нет,
рамка временно использует её акцент; исходный выбор восстанавливается при
возврате к прежней теме. Именованные оттенки сохраняются как `palette_<name>`.
По умолчанию используется `primary`.
Параметр **Толщина рамки окна** сохраняется для следующего перехода в scrolling.
Ползунки громкости, микрофона и яркости отображаются без теней.
Значки приложений на панели в тайлинге используют акцент выбранной темы.
Смена темы и акцента сохраняет положение указателя мыши.

Встроенные темы включают исходные палитры и отдельные терминальные цвета,
которые не меняются при выборе акцента. Источники указаны в
`shell/assets/schemes/SOURCES.md`. Светлые варианты Monokai и Vesper помечены
как адаптированные, поскольку исходные темы предлагают только тёмный вариант.
Палитра уже выбранной встроенной темы обновляется автоматически при запуске
новой версии шелла; выбранные тема, акцент и режим сохраняются. Импортированные
и динамические темы сохраняют свои цвета.

В **Панели → Панель задач → Рабочие столы → Вид значков** выбираются исходные
цвета приложений, тонированные значки или стандартные символы. Здесь же
настраиваются размер и отдельные цвета активных и неактивных значков.
Цвет выбирается из палитры текущей схемы; при смене темы выбранный оттенок
следует её палитре. Повторяющиеся цвета объединены. Ранее сохранённые
произвольные цвета остаются доступными до выбора нового оттенка.

В stacking центр уведомлений открывается снизу за 300 мс при стандартном
масштабе анимаций. Панель быстрых действий движется синхронно с ним;
повторное открытие использует уже подготовленное содержимое.

В **Обои и оформление → Скругление углов окон** задаётся радиус скругления окон
от 0 до 60 px. Значение 0 оставляет прямые углы. Параметр `windowRounding`
сохраняется в `tiling.json` и применяется сразу в scrolling и stacking.
Развёрнутые окна и соприкасающиеся тайлы при выключенных gaps сохраняют
прямые углы; при восстановлении возвращается выбранное скругление.

Возврат из stacking в тайлинг заполняет окно внутри рамки целиком, даже когда
приложение задерживает отрисовку изображения нового размера.

Сворачивание в stacking сохраняет размер и состояние клиента. Повторное нажатие
на кнопку приложения разворачивает текущую анимацию без скачка геометрии.
Невидимые вкладки дашборда прекращают опрос ресурсов и аудиовизуализацию;
анимации индикаторов и обложек приостанавливаются, пока их элементы скрыты.

Поле **Поиск настроек** ищет параметры и разделы, понимает английские названия
и распространённые русские запросы: «тени окон», «внешние отступы», «секунды».
Выберите результат мышью или стрелками и Enter: откроется нужная страница,
а найденный параметр прокрутится в видимую область и подсветится.

Переключение отступов **Win+G** одновременно меняет геометрию и маску скругления,
без промежуточного выезда острых углов за рамку. Контекстные меню приложений
появляются сразу, без длительного изменения прозрачности.

Фото, видео и другие материалы в просмотрщике Telegram Desktop и AyuGram
открываются плавающим окном над клиентом, на его мониторе и рабочем столе.
Оконный просмотр располагается по центру основного окна; переключение просмотра
в полноэкранный режим остаётся доступным. Основное окно сохраняет свою раскладку.
Обычное развёрнутое состояние просмотрщика не скрывает чат. Выход из полного
экрана и пересоздание окна Qt возвращают просмотр к плавающему окну.
Отдельный плеер «картинка в картинке» также остаётся плавающим; для AyuGram
поддержан заголовок `AyugramDesktop`. Он сохраняет свой размер и появляется
над основным клиентом.

## Темы и обои

```sh
hyprstack scheme list -n
hyprstack scheme set -n hyprstack-catppuccin -m light
hyprstack scheme set -n hyprstack-catppuccin -a blue -m dark
hyprstack wallpaper -f "$HOME/Pictures/Wallpapers/image.jpg"
hyprstack scheme set -n dynamic -m dark
```

Динамическая схема создаётся из основного цвета изображения через Pillow и
собственный подбор контрастных цветов. Названия вариантов сохранены для
интерфейса; алгоритм не воспроизводит Material You. Пресеты и собственные
схемы можно выбирать, создавать и импортировать через настройки оболочки.
Цвета записываются в состояние Hyprstack и `hypr/scheme/current.lua`.
Настройки браузера, терминала и других приложений не перезаписываются.

В **Обои и оформление → Цвета** доступны 18 встроенных тем: Catppuccin,
Gruvbox, Kanagawa, Everforest, Rosé Pine, Tokyo Night, Dracula, Nord, Solarized,
One, GitHub, Ayu, Nightfox, Monokai, Horizon, Oxocarbon, PaperColor и Vesper.
Цветные кнопки под карточкой выбирают акцент; он сохраняется при смене тёмного/светлого режима
и перезапуске оболочки. Светлые варианты тем адаптированы для интерфейса Hyprstack.
В CLI `-a` выбирает акцент, `scheme list -a` показывает его идентификаторы;
`-f` по-прежнему принимает вариант, например `mocha-blue`.

## Расход ресурсов

Базовая сборка отключает спектр звука и beat-анимации, прозрачность и размытие.
Изображения масштабируются при декодировании и кешируются в нужном размере.
Часы обновляются раз в минуту, когда секунды не показаны и запись не идёт.
Скрытые виджеты освобождают подписки на периодические службы.
Дашборд, запуск приложений и центр уведомлений сохраняют подготовленный
интерфейс после закрытия. Первое открытие ждёт завершения загрузки содержимого,
поэтому создание элементов не прерывает уже начатую анимацию. Кэширование
интерфейса не включает постоянную перерисовку в простое.

Для визуализатора нужны libpipewire, aubio и libcava; пересоберите с
`-DHYPRSTACK_AUDIO_VISUALIZER=ON`, затем включите функцию в настройках.
Она расходует дополнительные CPU и память. В базовой сборке визуализатор
недоступен, управление громкостью и медиаплеерами работает отдельно.

Погода отключена по умолчанию. В **Язык и регион → Погода** включите
**Включить погоду** и выберите способ определения города.
В **Местоположение для погоды** по умолчанию выбран **Автоматически по IP**. Для ручного
выбора переключитесь на **Город**, введите название и выберите результат
с нужным регионом и страной. Выбранный город сохраняется между перезапусками.
Вернуть определение по внешнему IP можно тем же переключателем.
**Провайдер погоды** выбирает **Open-Meteo** (по умолчанию, прогноз на 7 дней)
или **wttr.in** (прогноз на 3 дня). Ключ API не требуется.
В настройках дашборда есть переход **Настройки погоды** к этим параметрам.
Включение виджета погоды
в настройках дашборда также включает сервис. В `shell.json` это
`services.weatherEnabled`, `services.weatherProvider` и `services.weatherLocation`;
пустая строка в `weatherLocation` означает IP, строка `latitude,longitude`
задаёт точные координаты. `weatherLocationName` и `weatherLocationLabel`
сохраняют название выбранного города и его регион для интерфейса.
При сетевой ошибке сохраняется последний полученный прогноз и запрос повторяется
через минуту. Если основной сервис определения IP недоступен, используется
запасной. **Обновить погоду** обновляет прогноз вручную; статус показывает город
или причину ошибки. Смена города или провайдера не принимает ответы от предыдущего запроса.

## Запросы авторизации

Системные запросы пароля Polkit показывает сама оболочка. Окно появляется по
центру активного монитора и использует текущую палитру, шрифты, масштаб и
скругления Hyprstack. При нескольких доступных учётных записях можно выбрать,
от чьего имени выполняется авторизация. Enter отправляет ответ, Esc отменяет
запрос; кнопка с глазом показывает или скрывает пароль. После отправки, ошибки
или смены пользователя поле очищается. Поддерживаются также дополнительные
запросы PAM и сообщения системы.

Сеанс не запускает отдельный агент GNOME/KDE/LXQt. При ручном запуске стороннего
агента остановите его перед запуском оболочки: Polkit принимает только один
агент на сеанс. Проверка регистрации:

```sh
qs -p "${XDG_DATA_HOME:-$HOME/.local/share}/hyprstack/shell" ipc call polkit status
```

Значение `registered: true` означает, что запросы обрабатывает Hyprstack.

## Блокировка

Оболочка использует системный PAM-сервис `hyprlock`; она не устанавливает и
не изменяет `/etc/pam.d`. Для другого корректного системного сервиса задайте
`HYPRSTACK_PAM_SERVICE` в окружении сеанса. Fingerprint/Howdy отключены по
умолчанию и требуют самостоятельной настройки. Разблокировка через IPC
без проверки пароля не предоставляется.
