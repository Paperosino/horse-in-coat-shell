# Настройки hics

Меню настроек разделено по назначению:

- **Оформление:** темы и обои, панели, док, окна и рабочие столы.
- **Устройства:** экран, звук, принтеры и накопители.
- **Ввод и управление:** клавиатура, мышь, тачпад, горячие клавиши и доступность.
- **Подключения:** сеть, Bluetooth, запись и демонстрация экрана.
- **Приложения:** библиотека, приложения по умолчанию, автозапуск, уведомления, расширения и ИИ.
- **Система:** питание и блокировка, язык и регион, дата и время, службы и сведения о системе.

Шаг и предел громкости находятся в «Аудио», плеер, тексты песен и визуализатор —
в «Аудио → Медиа и тексты». Шаг яркости находится в «Экране», интервал поиска
сетей — в «Сети», автоматическая цветовая схема — в «Оформлении».
Поиск открывает соответствующий раздел и выделяет найденный параметр.

Файлы находятся в `${XDG_CONFIG_HOME:-$HOME/.config}`:

| Файл | Назначение |
| --- | --- |
| `hics/shell.json` | Панели, темы, уведомления, погода и анимации |
| `hics/layouts.json` | Scrolling / stacking |
| `hics/workspaces.json` | Рабочие столы и распределение по мониторам |
| `hics/appearance.json` | Темы иконок и курсора, размер курсора |
| `hics/effects.json` | Размытие и тени |
| `hics/tiling.json` | Рамки, отступы, фокус по наведению и автопрокрутка |
| `hics/hypr-vars.lua` | Приложения, горячие клавиши, оформление Hyprland |
| `hics/monitors.lua` | Настройки экранов |
| `hics/keyboard.lua` | Раскладки и параметры клавиатуры |
| `hics/dock.json` | Док: включение, положение, размер значков и кнопка меню приложений |
| `hics/notification-rules.json` | Правила уведомлений по приложениям и срок временной паузы |
| `hics/plugins.json` | Расширения и их настройки |
| `hics/live-wallpapers.json` | Видео и Wallpaper Engine для каждого экрана |
| `hics/assistant.json` | Провайдер, модель и настройки ИИ |
| `hics/system-controls.json` | Дополнительные параметры системы |
| `hics/system.lua` | Применение дополнительных параметров Hyprland |
| `hics/local.lua` | Дополнительные настройки Hyprland |
| `hics/hypr-user.lua` | Подключение hics и пользовательских файлов |
| `hics/monitors/<имя экрана>/shell.json` | Настройки отдельного монитора |

Настройки оболочки доступны в интерфейсе. `hypr-vars.lua` возвращает таблицу;
дополнительные вызовы `hl.config` и `hl.monitor` размещайте в `local.lua`
и `monitors.lua`.

## Экраны и клавиатура

Режим, расположение и масштаб экранов выбираются автоматически.
Переопределения задавайте в `monitors.lua`, включая HDR и VRR.
Яркость встроенного экрана управляется через системную подсветку,
внешнего — через DDC/CI.

Страница **Настройки → Экран** управляет расположением мониторов
(перетаскиванием на схеме), разрешением, частотой обновления, масштабом,
ориентацией и VRR для каждого выхода. Изменения применяются кнопкой и
сохраняются в `monitors.lua` внутри помеченного управляемого блока:
содержимое вне меток сохраняется, сеанс применяется через `hl.monitor`.

Раскладка по умолчанию — `us`. Страница **Настройки → Клавиатура**
задаёт список раскладок (добавление из полного списка xkb, удаление,
порядок), вариант каждой раскладки, сочетание переключения, поведение
Caps Lock и compose-клавишу, Num Lock при входе, задержку и частоту
повтора. Настройки применяются сразу и сохраняются в `keyboard.lua`
в управляемом блоке (контент вне меток сохраняется, `local.lua`
применяется после и имеет приоритет). Пример `local.lua` для двух языков:

```lua
hl.config({ input = { kb_layout = "us,ru", kb_options = "grp:alt_shift_toggle" } })
```

С Home Manager Lua-настройки также можно задать декларативно:

```nix
programs.hics.extraConfig = ''
  hl.config({ input = { kb_layout = "us,ru", kb_options = "grp:alt_shift_toggle" } })
'';
```

Они применяются после `local.lua`; управляемый `hypr-user.lua` редактировать не нужно.

### Подсказка и управление по режимам

**Super+F1** открывает подсказку поверх окон. В ней можно выбрать режим окон;
выбран текущий активный режим, а список показывает его реальные сочетания,
включая пользовательские. Повторное нажатие или Escape закрывает подсказку.

| Сочетание | Действие |
|---|---|
| Super + стрелки | Фокус по направлению |
| Super + Shift + стрелки / H J K L | Перемещение окна; на холсте — сдвиг по его координатам |
| Super + Ctrl + Shift + стрелки | Изменение размера окна шагами по 32 px |
| Super + Ctrl + стрелки | В canvas — движение камеры; в остальных режимах — навигация |
| Super + Ctrl + F | В canvas — показать все окна; в scrolling — переключить ширину колонки |
| Super + Ctrl + Enter | В canvas — показать выбранное окно по центру |
| Super + Ctrl + = / − / 0 | В canvas — приблизить / отдалить / масштаб 100% |
| Super + Ctrl + A | Упорядочить окна canvas |
| Super + Ctrl + Z / Shift + Z | Отменить / повторить действие canvas |
| Super + Ctrl + Backspace | Вернуться к предыдущему виду canvas |

В scrolling Super+H/L выбирают колонку, Super+J/K — рабочий стол.
В tiling, stacking и canvas эти же клавиши выбирают окно по направлению.

## Окна

**Super+H/L** на краю ленты переходит к окну на соседнем мониторе
в выбранном направлении. Пустые рабочие столы пропускаются, перехода по кругу нет.

**Super+Alt+Space** переключает плавающее состояние; размер и положение окна
сохраняются. Диалоги и просмотрщики Telegram/AyuGram остаются плавающими.

В stacking **Alt+Tab** выбирает окно; отпускание Alt или Enter активирует его,
Esc отменяет выбор. Свёрнутые окна также участвуют в переключении.

Подробнее о режимах — в [описании раскладки](shell/assets/hyprland/README.md).

## Жесты тачпада

| Жест | Действие |
| --- | --- |
| 3 пальца влево / вправо | Прокрутка колонок в scrolling |
| 3 пальца вверх / вниз | Следующий / предыдущий рабочий стол в scrolling |
| 4 пальца вверх | Открыть обзор |
| 4 пальца вниз | Подтвердить выбор и закрыть обзор |

В обзоре три пальца меняют выделение. В stacking работают только жесты обзора.
Вертикальная навигация ограничена рабочими столами текущего монитора.

Количество пальцев задаётся в таблице `hypr-vars.lua`:

```lua
return {
    gestureFingers = 3,          -- Колонки
    workspaceSwipeFingers = 3,   -- Рабочие столы
    gestureFingersMore = 4,      -- Обзор; отдельное количество пальцев
}
```

Добавьте нужные поля в существующую таблицу и выполните `hyprctl reload`.

## Язык и регион

**Язык и регион → Язык интерфейса**: русский, English или язык системы.
В `shell.json` это `general.language`: `"ru_RU"`, `"en_US"` или `""`.
Для отдельного запуска CLI: `HICS_LANGUAGE=en_US hics …`.

## Панель и масштаб

В **Панели → Панель задач → Видимость элементов** выберите **Все экраны**
или конкретный монитор. Индивидуальные параметры сохраняются в
`monitors/<имя>/shell.json` и имеют приоритет над общими.

Параметры оформления:

| Раздел настроек | Параметры в файлах |
| --- | --- |
| Обои и оформление → Масштаб интерфейса | `shell.json`: `appearance.scale`, 0.5–2.0 |
| Обои и оформление → Отступы между окнами | `tiling.json`: `gapsIn`, `gapsOut`, 0–100 px; Super+G переключает отступы |
| Обои и оформление → Скругление углов окон | `tiling.json`: `windowRounding`, 0–60 px |
| Обои и оформление → Тени | `effects.json`: `windowShadows`, `uiShadows`, `shadowSize`, `shadowOpacity` |
| Обои и оформление → Цвет рамки окна | `tiling.json`: `focusBorderColor`, оттенок текущей темы |
| Панели → Панель задач → Рабочие столы → Вид значков | Исходные цвета, тонировка или символы |

В тайлинге фокус по наведению включён по умолчанию. Отключить:
**Обои и оформление → Переключение окон при наведении в тайловом режиме**
(`tiling.json`: `focusOnHover`). При отключении у края скрытого окна появляется
кнопка перехода к нему. В stacking фокус меняется по нажатию.

**Обои и оформление → Прокрутка средней кнопкой мыши** (`tiling.json`: `autoscroll`):
удержите колёсико около 0,2 секунды и отпустите, затем двигайте мышь для прокрутки.
Esc, клик или вращение колёсика останавливают её. Короткий средний клик
и Ctrl+средняя кнопка сохраняют действие приложения.

## Темы и обои

**Обои и оформление → Цвета**: 18 встроенных тем, светлый / тёмный режим и акцент.
Список тем и источники — в [описании палитр](shell/assets/schemes/README.md).
**Обои → Обзор** выбирает изображение; до выбора используется однотонный фон.
Схема `dynamic` строит палитру по обоям.

```sh
hics scheme list -n
hics scheme list -a
hics scheme set -n hics-catppuccin -a blue -m dark
hics wallpaper -f "$HOME/Pictures/Wallpapers/image.jpg"
hics scheme set -n dynamic -m dark
```

Выбор сохраняется в состоянии hics и `hypr/scheme/current.lua`.
Настройки других приложений не меняются. Пресеты можно создавать
и импортировать через интерфейс.

## Расход ресурсов

Размытие, прозрачность и звуковой визуализатор по умолчанию отключены.
Для сборки визуализатора из исходников нужны libpipewire, aubio и libcava.
Добавьте `-DHICS_AUDIO_VISUALIZER=ON` к команде CMake, пересоберите
и включите визуализатор в настройках.

## Погода

Включите **Язык и регион → Погода → Включить погоду**.
Местоположение: автоматически по IP или поиск города. Провайдеры:
**Open-Meteo** (7 дней) и **wttr.in** (3 дня); ключ API не нужен.

В `shell.json`: `services.weatherEnabled`, `services.weatherProvider`,
`services.weatherLocation` (пусто — IP; `latitude,longitude` — координаты).
Кнопка **Обновить погоду** запрашивает прогноз вручную.

## Запросы авторизации

Оболочка содержит агент Polkit. Отключите сторонний агент, чтобы избежать
конфликта регистрации. Штатные запросы Polkit отображаются в оформлении оболочки
поверх окон на активном экране. GNOME Keyring и редактор снимков остаются штатными
GTK-приложениями: их цвета синхронизируются с любой цветовой схемой оболочки,
включая пользовательские и динамические схемы. Установщик и запуск сеанса
настраивают GTK 2/3/4 и палитры Qt 5/6 (qt5ct/qt6ct, стиль Fusion).
`gtk.css` управляется оболочкой: старые импорты тем заменяются; цвета хранятся
в `gtk-3.0/hics.css` и `gtk-4.0/hics.css`. Настройки значков и шрифтов
сохраняются. При смене схемы палитры генерируются заново. Уже запущенным
приложениям может понадобиться перезапуск. Приложения с собственными темами
могут не использовать системную палитру.
Установленные Flatpak-приложения получают такую же палитру в собственных
`~/.var/app/<app-id>/config`: GTK 2/3/4, qt5ct/qt6ct и KDE (`kdeglobals`).
Синхронизация выполняется установщиком, при входе и смене схемы; запущенный
сеанс обнаруживает новые приложения каждые 30 секунд. Доступ ко всей домашней
папке и новые разрешения Flatpak не выдаются. Qt-палитра используется при наличии
соответствующего платформенного плагина в runtime приложения; собственное
оформление приложений не заменяется принудительно.
Пароли обрабатывают прежние системные службы.

На холсте модальные и дочерние диалоги появляются по центру видимого экрана
поверх окон, независимо от положения камеры.

## Блокировка

Используется системный PAM-сервис `hyprlock`. Другой сервис можно задать через
`HICS_PAM_SERVICE` в окружении сеанса. Fingerprint/Howdy настраиваются отдельно.

## Питание и блокировка

Страница **Настройки → Питание и блокировка** задаёт таймауты блокировки
экрана, выключения экрана (DPMS) и перехода в сон: пресеты, своё значение
в минутах или «Никогда». Дополнительно: блокировка перед переходом в сон
и запрет режима бездействия при воспроизведении медиа или во время зарядки.

Значения хранятся в `shell.json` в списке `general.idle.timeouts`
(интервалы в секундах, по одной записи на действие). Бездействие
обрабатывается самой оболочкой, hypridle не требуется.

Дополнительные разделы: [возможности рабочего стола](DESKTOP_FEATURES.md), [API и совместимость плагинов](PLUGINS.md).

## Обзор и приложения по умолчанию

В обзоре перетащите окно на другое окно, чтобы поменять их местами, или на
область другого рабочего стола для переноса. Колесо мыши переключает рабочие
столы обзора; отпускание окна за пределами монитора отменяет перенос.

В «Приложения → Приложения по умолчанию» доступны браузер и категории файлов:
текст, изображения, видео, музыка, PDF, электронные книги, архивы, офисные
документы, таблицы, презентации, почта и торренты. Выбор использует список
приложений лаунчера и сохраняет XDG MIME-ассоциации, включая HTTP/HTTPS.
Поддерживающие выбранный формат приложения показываются первыми.

## Режимы окон и бесконечный холст

«Окна и рабочие столы» предлагает тайлинг (dwindle), скроллинг, стакинг и
бесконечный холст Phantomat. Выбор режима и параметры холста сохраняются в
`hics/layouts.json`. Этот файл используется и оболочкой, и Lua-конфигурацией
Hyprland. Холст включается только по выбору пользователя. Сборка включает плагин
для того же ABI Hyprland; отдельная установка через hyprpm не требуется.

Переключатель «Режим расположения окон» доступен в каталоге виджетов панели.
Его можно поместить в левую, центральную или правую зону либо удалить.
Сочетание Super+Ctrl+Shift+M циклически переключает четыре режима.
Холст независим от стакинга: заголовки и расположение панели не меняются,
при выходе восстанавливаются исходный режим, размеры и рабочие столы окон.
Super+O включает обзор/поиск окон и возвращает к работе с приложением.
Super+средняя кнопка с движением перемещает камеру. Ctrl+колесо и жест щипка
меняют масштаб, в обзоре достаточно колеса. Обычное колесо в приложении
остаётся прокруткой. Super+Ctrl+= / − / 0 — приблизить, отдалить, 100%.
Super+стрелки или H/J/K/L выбирают окно по направлению;
Super+Ctrl+стрелки перемещают камеру, Super+Shift+стрелки — окно.
Alt+Tab переключает недавние окна, Super+Alt+Space вписывает окно в экран.
Super+ЛКМ перемещает окно, Super+ПКМ меняет его размер.
В обзоре Enter/щелчок выбирает окно, Escape возвращает назад.
В настройках доступны масштаб обзора, сетка, привязка, мини-карта,
сохранение окон, действия камеры и фокус при наведении (по умолчанию выключен).
«Липкие окна» (`canvasSticky`, по умолчанию выключено) удерживают соседние грани
с отступом «New window spacing» (`canvasGap`). Прилипание срабатывает в пределах
12 экранных пикселей; движение дальше 36 px от удерживаемой грани освобождает окно
и позволяет перекрыть соседа. Прилипание действует во время перетаскивания,
а привязка к сетке не переопределяет удерживаемую грань.

Управление адаптировано из [официального примера Phantomat для Omarchy](https://github.com/kaolti/phantomat/blob/main/examples/spatialoverview.lua)
и [конфигурации DriftWM Rose Pine Dawn](https://github.com/malbiruk/driftwm-dotfiles/blob/main/.config/driftwm/config.toml).
DriftWM — отдельный композитор; здесь используется Phantomat внутри Hyprland.

«Панели → Панель задач → Рабочие столы → Скрывать все пустые индикаторы»
оставляет только занятые столы и текущий, включая скрытие пустых промежутков.
Прежняя настройка «Показывать незанятые» регулирует только пустой хвост.

## Системные устройства и службы

«Принтеры и накопители» содержит очереди CUPS, выбор системного принтера по
умолчанию, паузу/возобновление печати, свои задания и их отмену. Сетевые принтеры
ищутся через CUPS; также можно ввести IPP/IPPS-адрес для IPP Everywhere.
Удаление очереди требует повторного нажатия и подтверждения прав администратора.
В списке накопителей доступны размер, свободное место, файловая система,
подключение томов и открытие в файловом менеджере.

«Язык и регион → Дата и время»: часовой пояс, NTP и ручная установка часов.
«Питание и блокировка → Профиль энергопотребления»: только профили, поддержанные
оборудованием и power-profiles-daemon.

C++-служба `hics-system.service` активируется по D-Bus при открытии этих
настроек. Дополнительно нужны CUPS для печати, UDisks2 для дисков и
power-profiles-daemon для профилей. Если служба отсутствует, страница сообщает
об этом и не показывает работающие переключатели для недоступной функции.

## Диски: подключение, состояние и обслуживание

В **Настройки → Принтеры и диски → Диски** выберите «Настройки, состояние
и обслуживание» у нужного раздела. Автомонтирование при загрузке, точка
монтирования внутри `/mnt` или `/media`, режим чтения и переключатели
`noexec`, `nosuid`, `nodev`, `nofail`, `noatime` сохраняются через UDisks
в `/etc/fstab` после подтверждения Polkit. Существующие дополнительные
опции сохраняются. Изменения действуют при следующем подключении.
Системные точки и разделы с несколькими записями монтирования защищены.

S.M.A.R.T. показывает состояние SATA/NVMe, температуру, наработку,
ошибки и доступные сведения об износе. Обновление с диска и короткий
или расширенный самотест запускаются отдельно; обычное обновление
страницы читает кэш UDisks и не будит спящие диски.

Для подключённых SSD доступен TRIM (`fstrim`), для HDD с ext4 —
дефрагментация (`e4defrag`). Задачи выполняются системной службой
с низким приоритетом, показывают состояние и допускают остановку.
Другие файловые системы не получают неподходящую кнопку дефрагментации.
Операции требуют UDisks, а обслуживание — подтверждения Polkit.

В холсте обычная СКМ внутри приложения передаётся приложению, включая
нажатие с перетаскиванием. Панорамирование: СКМ на пустом месте,
Super+СКМ или Space+ЛКМ. Перетаскивание файлов между областями
приложения использует координаты камеры и отдельный маршрут Wayland DnD.

## Иконки, курсоры и расположение настроек

В **Кастомизация → Иконки приложений / Внешний вид курсора** доступны поиск
по названию, образцы установленной темы и явное применение. Общая тема
применяется к GTK 2/3/4, Qt 5/6 и установленным Flatpak-приложениям;
курсор также задаётся для X11/XWayland и Hyprland/Wayland. Для Qt установщик
включает qt5ct и qt6ct. Параметры сохраняются в конфигурациях соответствующих
тулкитов и в `environment.d/90-hics-appearance.conf`; параметры других
секций сохраняются. Некоторые приложения обновляют оформление после перезапуска.

Темы читаются из `~/.local/share/icons`, `~/.icons` и каталогов `icons`
в `XDG_DATA_DIRS`. Для предпросмотра курсоров читаются реальные Xcursor-изображения,
для иконок учитывается наследование темы. Flatpak получает настройки в конфигурации
установленных приложений и использует стандартные `/run/host/*/icons` без выдачи
доступа ко всей домашней папке. Поддержка зависит от тулкита и среды выполнения;
приложения со встроенным оформлением могут не следовать системной теме.

Основное меню сгруппировано по назначению. Док находится в **Панели**,
расположение виджетов — в **Панели → Компоновка панели состояния**,
горячие клавиши — в **Клавиатура и мышь**, плагины, ИИ, автозапуск и приложения
по умолчанию — в **Приложения**. Старые ссылки на эти разделы и поиск
настроек ведут на соответствующие вложенные страницы.

Нажатие на всплывающее уведомление или его заголовок/текст в истории вызывает
стандартное действие приложения (`default`), если оно передано. Это позволяет
самому приложению открыть нужный чат, письмо или документ. Без такого действия
hics переключается на последнее использованное окно отправителя; свёрнутое окно
восстанавливается. Переход использует тот же механизм, что и док, включая
навигацию камеры холста. Если открытого окна нет, используется desktop entry
приложения. Для сохранённой истории действия отправителя после его перезапуска
могут быть недоступны; в таком случае открывается окно приложения.
Поведение регулируется параметром «Открывать приложение по нажатию» в
«Уведомлениях». Кнопки других действий выполняют только выбранное действие.

После действия уведомления hics проверяет фактический фокус окна и повторяет
запрос при смене фокуса во время закрытия панели. Всплывающие уведомления
располагаются под открытой панелью состояния в общей blob-поверхности; высота
списка ограничивается оставшейся свободной областью экрана.

## VPN NetworkManager

В разделе «Подключения → Сеть → VPN» находятся сохранённые профили, создание, импорт,
экспорт, подключение и удаление. Редактор на C++/libnm работает с настройками
NetworkManager напрямую. Поддержаны формы OpenVPN, WireGuard, PPTP, L2TP/IPsec
(пароль, пользовательские и машинные сертификаты, PSK, IKE/ESP и параметры PPP),
OpenConnect, VPNC, strongSwan, Libreswan, SSTP, Fortinet и SSH.
Для других установленных плагинов доступны импорт при поддержке плагином и
редактор словаря параметров. Неизвестные параметры существующих профилей сохраняются.

DNS, домены поиска и маршрутизации (`~domain`, `~.`), приоритет DNS, шлюз,
адреса, маршруты, правила маршрутизации и запрет маршрута по умолчанию задаются
отдельно для IPv4 и IPv6. Отрицательный приоритет DNS позволяет исключить DNS
подключений с более высоким приоритетом. WireGuard поддерживает несколько peers,
генерацию закрытого ключа, endpoint, allowed IPs и keepalive.

Страница плагинов показывает обнаруженные протоколы и поддерживаемые операции.
Установка пакета запрашивает системную авторизацию через Polkit. WireGuard
встроен в NetworkManager. strongSwan и Libreswan — альтернативные IPsec-реализации;
их нельзя устанавливать вместе. Наличие пакетов, например SSTP, зависит от
репозиториев дистрибутива; автоматической установки из AUR нет.

Сохранённые пароли подставляются в поля редактора в скрытом виде. Кнопка с глазом
показывает или скрывает значение; пустое поле сохраняет существующий секрет. Агент паролей принимает запросы только от NetworkManager. При поддержке
плагином протокола external UI поля авторизации отображает сама оболочка;
сложные браузерные сценарии выполняет официальный помощник плагина. Пароли
из запроса можно сохранить в системной связке ключей. Экспорт содержит секреты
и записывается с правами `0600`; формат `.nmconnection` сохраняет полный профиль,
другие форматы используют экспорт плагина или WireGuard `.conf`.

Проверки: `tests/test_vpn_native.py` использует частную D-Bus-шину и проверяет
сохранение секретов/параметров, маршруты, DNS, импорт, экспорт и доступ к агенту.
Соединение с конкретным VPN-сервером требует его адреса и учётных данных.

Темы GTK2 используют сгенерированный RC-файл, GTK3 — CSS, GTK4/libadwaita —
CSS и переменные цветов. Настройки иконок и курсоров сохраняются. Уже запущенные
приложения, которые читают тему только при старте, необходимо переоткрыть.
Реальные цвета виджетов и отрисовку кнопок проверяет `tests/integration_gtk_palette.py`.

Основной редактор VPN показывает только параметры выбранного способа входа;
логика разделения формы следует [редактору KDE plasma-nm](https://github.com/KDE/plasma-nm/tree/master/vpn).
DNS, маршруты, настройки шифрования и служебные параметры доступны по кнопке
«Расширенные настройки». Сворачивание разделов сохраняет введённые значения.
Список VPN встроен в страницу сети; отдельного пункта VPN в боковом меню нет.

Сетевой виджет панели объединяет Wi-Fi, Ethernet и сохранённые VPN-профили.
Нажатие строки подключает или отключает выбранное соединение. Одновременно
видны не больше десяти строк подключений; остальные доступны прокруткой,
позиция которой сохраняется при обновлении статусов. Кнопка «Настройки сети»
открывает общую страницу сети. На небольших экранах высота дополнительно ограничена.

Удаление VPN доступно кнопкой с корзиной рядом с профилем и требует подтверждения.
Окно авторизации подставляет доступные сохранённые значения и сохраняет введённый
текст при обновлениях состояния. Закрытые ключи и общие ключи WireGuard тоже
скрыты по умолчанию и имеют кнопку показа.

При подключении через Libreswan оболочка проверяет готовность `ipsec.service`
и при необходимости запускает её через systemd с системной авторизацией.
Подробные причины `VpnStateChanged` имеют приоритет над общим состоянием
соединения: сообщение с конкретной причиной не заменяется ошибкой `reason 0`.

Libreswan 5 по умолчанию запрещает устаревший IKEv1. Если сервер требует
именно этот протокол, администратор может разрешить его параметром
`ikev1-policy=accept` в секции `config setup` файла `/etc/ipsec.conf`
и перезапустить `ipsec.service`, предварительно сохранив конфигурацию.
Оболочка не меняет эту глобальную политику автоматически. Если после этого
сервер не отвечает на первый пакет IKE, проверьте адрес, требуемый сервером
протокол и доступность UDP 500/4500: изменение пароля такой тайм-аут не устраняет.


В редакторе VPN поле «Тип VPN» позволяет сменить протокол существующего
соединения. Выбор требует подтверждения; сервер и имя пользователя переносятся
только между совместимыми полями, а секреты и параметры старого плагина не
переходят в новый. Имя, UUID, DNS и маршруты профиля сохраняются. До сохранения
можно вернуться к предыдущему типу и восстановить его несохранённые поля.
Для смены типа работающий VPN необходимо отключить.

Список типов показывает и недоступные плагины: их можно установить прямо при
создании или смене типа VPN. L2TP/IPsec показывает включение IPsec, общий ключ
или сертификаты в основной форме; Libreswan — выбор версии IKE. Названия режимов
авторизации отображаются понятными подписями, а дополнительные параметры
протокола остаются в расширенных настройках. Импорт доступен для плагинов,
которые объявляют поддержку импорта.

### Инструменты рабочего пространства

В настройках появились страницы **История буфера обмена**, **Редактор горячих клавиш** и **Восстановление сессии**. Параметры хранятся в `~/.config/hics/workspace.json`, снимки и постоянная история — в `~/.local/state/hics/workspace`. Файлы состояния создаются с правами 0600, новые каталоги — 0700.

История поддерживает текст и изображения, закрепление, поиск, редактирование текста, паузу, импорт старой истории cliphist, ограничения размера и количества записей, срок хранения и исключения по регулярным выражениям. Закреплённые записи не удаляются обычной очисткой и ограничением количества. Можно отключить запись на диск, захват при блокировке и хранение после выхода. Содержимое с метками секретов игнорируется; исключение по активному приложению является дополнительной эвристикой, а не гарантией определения источника. История по умолчанию сохраняется на диск: для конфиденциальной работы отключите постоянное хранение или запись истории. Полная очистка удаляет постоянное и временное хранилища.

Редактор сохраняет исходные Lua-обработчики действий при переназначении, проверяет конфликты в пределах подкарты, поддерживает физические клавиши, пользовательские команды, флаги повторения/отпускания/блокировки и импорт/экспорт JSON. При обновлении существующего конфигурационного файла Hyprland добавляется загрузчик редактора; исходный файл сохраняется рядом с суффиксом `.before-hics-shortcuts`. Произвольные сторонние изменения привязок после загрузки конфигурации могут потребовать её повторной загрузки.

Восстановление сессии включается отдельно. Можно создавать именованные снимки, выбирать приложения перед запуском, редактировать аргументы команды, рабочий каталог, задержки, экран, рабочий стол и геометрию каждого окна. Настраиваются автоматические снимки, поведение при входе, исключения, повторный запуск работающих приложений, ожидание появления окна, восстановление фокуса, полноэкранного состояния и режима оболочки. Команды процессов и их потенциальные секреты не считываются из `/proc`: запуск определяется установленным `.desktop`, неизвестные приложения требуют ручного указания команды.

Поддерживается импорт списков запуска GNOME (`~/.config/gnome-session/saved-session`) и KDE (`~/.config/ksmserverrc`) с предварительным просмотром, а также экспорт JSON и переносимых файлов `.desktop`. В GNOME/KDE доступен запуск приложений через XDG Autostart при включённой совместимости. Размещение окон, рабочие столы и надёжное обнаружение уже открытых окон доступны в Hyprland. Внутреннее состояние приложений, вкладки, документы, точное дерево тайлинга и приватные протоколы восстановления другого композитора не переносятся. Приложение может самостоятельно восстанавливать свои документы.

Команды: `hics workspace list`, `hics workspace capture "Название"`, `hics workspace restore ID`, `hics workspace startup`. Новый отдельный системный сервис не требуется: захват буфера и автоматические снимки работают внутри оболочки, `hics-workspace` устанавливается пакетом для входа и выхода из сессии.

Меню дока показывает список окон с переходом по заголовку, закрытием и принудительным завершением. Предпросмотр появляется после наведения на заголовок на 1 секунду; после первого показа переключается сразу, пока не истекут 5 секунд после ухода курсора. Предпросмотр соединяется с меню общей поверхностью. Принудительное завершение посылает SIGKILL процессу выбранного окна и может закрыть другие окна этого же процесса.

Каталог приложений отслеживает `.desktop` в пользовательских и системных каталогах XDG, включая вложенные папки, и периодически сверяет новые каталоги. Изменения становятся доступны без перезапуска оболочки. Основной запуск использует GIO и учитывает DBusActivatable и поля запуска desktop-файла.

Холст запоминает положение камеры для открытых окон, совместно видимых при масштабе 100%. Переход из дока, уведомления или переключателя возвращает к этому виду, сохраняя соседние окна в их частях экрана. Память привязана к живым идентификаторам окон и текущей геометрии: закрытые участники удаляются, перемещение или изменение размера сбрасывает устаревшую группу, а следующий устойчивый вид записывается заново. Память не растёт вместе с историей закрытых окон и не переносится на новое окно с повторно использованным адресом. Она действует в текущем сеансе композитора; постоянное размещение и восстановление сессии настраиваются отдельно.

Ввод холста сохраняет последовательность событий XWayland: перед колесом не генерируется повторное движение мыши с неизменными координатами. Это восстанавливает доставку прокрутки Qt Quick/XInput-приложениям, включая тип окна, используемый MAX.
