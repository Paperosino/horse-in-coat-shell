# Дополнительные возможности рабочего стола

Реализации вдохновлены AngelOS и локальным settings-ui; компоненты адаптированы
к текущим токенам, формам и страницам Hyprstack. Происхождение палитр и данных
поисковых систем указано в THIRD_PARTY.md.

* **Клавиатура и мышь:** отдельные страницы мыши, тачпада, курсора и жестов.
* **Окна и рабочие столы:** фокус, изменение размера и переключение.
  Параметры совместимости отрисовки находятся в разделе экрана.
  Дублирующие настройки эффектов и анимаций исключены из этих страниц;
  оформление управляется существующей кастомизацией оболочки.
  Показываются только параметры, доступные текущему Hyprland. Изменения применяются
  через Lua API, сохраняются в system-controls.json и system.lua. Автоматического
  изменения всех значений при установке нет.
* **Бесконечный 2D-холст (Infinite Canvas):** концепция и архитектура пространственного
  управления окнами на непрерывной плоскости с виртуальной камерой, зумом, кластерами
  и миникартой описаны в docs/INFINITE_CANVAS.md.
* **Приложения → Автозапуск** и **Службы → Пользовательские службы и таймеры**:
  пользовательский автозапуск, создание записи автозапуска,
  пользовательские службы и таймеры systemd. Управление системными root-службами
  сюда не включено.
* **ИИ:** Ollama или OpenAI-совместимый сервер, список моделей, потоковый ответ,
  остановка, история, копирование, системная инструкция. Для Ollama отдельно
  установите сервер и загрузите модель. По умолчанию используется localhost:11434;
  внешние запросы выполняются только по выбранному адресу. Ключ хранится отдельным
  файлом с правами 0600 либо берётся из HYPRSTACK_ASSISTANT_KEY. Контекст системы
  передаётся только при включении соответствующей опции. Ассистент не выполняет команды.
* **Обои и оформление → Темы:** библиотека палитр, восемь дополнительных палитр AngelOS, импорт JSON
  (включая основные цветовые роли Noctalia), расписание дня/ночи и отдельные темы.
* **Обои и оформление → Живые обои:** встроенное циклическое воспроизведение видео через Qt Multimedia;
  Wallpaper Engine через linux-wallpaperengine, поиск Steam/Flatpak-библиотек,
  настройки каждого экрана, FPS, звук, масштабирование, свойства проекта,
  пауза при полноэкранном приложении/работе от батареи и ротация плейлиста.
  Поддержка конкретных Workshop-сцен зависит от linux-wallpaperengine.
* **Расширения:** см. PLUGINS.md для API, готовых примеров и границ совместимости.

Основные файлы в ~/.config/hyprstack: assistant.json, assistant-key.json,
plugins.json, live-wallpapers.json, system-controls.json, system.lua.
История ИИ и резервные копии расширений находятся в ~/.local/state/hyprstack.
