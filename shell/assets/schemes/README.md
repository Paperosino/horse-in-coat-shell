# Встроенные цветовые схемы

В `presets.json` находятся 18 парных тёмных и светлых тем: Catppuccin, Gruvbox,
Kanagawa, Everforest, Rosé Pine, Tokyo Night, Dracula, Nord, Solarized, One,
GitHub, Ayu, Nightfox, Monokai, Horizon, Oxocarbon, PaperColor и Vesper.

Каждая тема содержит полную именованную палитру исходного проекта, 16 цветов
ANSI и варианты акцента. `../theme_manager.py` преобразует их в цветовые роли
интерфейса. Роли `palette_<name>` сохраняют исходные RGB; выбор акцента
не изменяет исходные и терминальные цвета. Источники и адаптации перечислены
в [SOURCES.md](SOURCES.md).

В настройках «Обои и оформление → Цвета» карточка выбирает тему, а цветные
кнопки под ней — акцент. Переключение светлого/тёмного режима сохраняет акцент.
Цвет рамки окна выбирается отдельно из основных оттенков выбранной темы;
повторы объединены, полная палитра остаётся доступна внутри схемы.

CLI устанавливается вместе с Hyprstack из корня проекта:

```sh
hyprstack scheme list -n
hyprstack scheme list -a
hyprstack scheme set -n hyprstack-kanagawa -a blue -m dark
```

Kanagawa использует Wave для тёмного и Lotus для светлого режима. Встроенная
палитра выбранной темы обновляется при запуске новой версии оболочки с
сохранением темы, акцента и режима. Собственные и динамические схемы сохраняют
свои цвета. Выбор схемы и настройка акцента описаны в
[настройках](../../../CONFIGURATION.md).
