# Размещение окон и интеграция с Hyprland

Действующая интеграция находится в `layouts.lua` и конфигурации `config/`.
Она использует нативную раскладку `scrolling` Hyprland 0.56.2 и модифицированный
hyprbars. Установка из корня проекта подключает нужный файл через
`~/.config/hyprstack/hypr-user.lua`. Подробные пользовательские настройки
описаны в [CONFIGURATION.md](../../../CONFIGURATION.md).

**Super+Ctrl+Shift+M** переключает scrolling и stacking во всём сеансе.
При переходе в stacking обычные окна собираются на текущем рабочем столе
своего монитора. Возврат в scrolling восстанавливает мониторы, рабочие столы,
порядок колонок и их ширину. Положение, размер и развёрнутое состояние в
stacking сохраняются отдельно. Новое окно не переставляет уже открытые окна.

## Тайлинг

Новое обычное окно занимает колонку полной высоты и половины рабочей ширины.
Браузеры получают полную ширину через правило `scrolling_width` до появления
окна. **Super+Ctrl+F** меняет ширину колонки между половиной и полной шириной;
пользовательские размеры сохраняются при смене режима.

**Super+Alt+Space** переводит окно в плавающее состояние и обратно. Положение
и размер плавающего окна сохраняются при переходах между режимами.
Диалоги, просмотрщик Telegram и отдельный плеер AyuGram остаются плавающими.
Основное окно Telegram сохраняет тайлинг; плеер `AyugramDesktop` не скрывает чат.

**Super+H/L** выбирает соседнюю колонку; на краю ряда переходит на монитор
в выбранном физическом направлении. Перехода по кругу нет.
Пустой текущий рабочий стол соседнего монитора пропускается.
**Super+J/K** меняет рабочий стол вертикально.

Серверные заголовки в тайлинге скрыты. Акцентную рамку можно настроить отдельно
от акцента темы. Нативные запросы сворачивания и обычного развёртывания тайла
не нарушают раскладку; полный экран остаётся доступен. При изменении размера
весь клиентский буфер заполняет рамку, включая задержку нового буфера.

## Stacking

Фокус меняется по нажатию, окна можно перемещать за заголовок и менять размер
за границы. Добавленные заголовки имеют адресные кнопки сворачивания,
развёртывания/восстановления и закрытия. Двойное нажатие разворачивает окно.
Кнопки клиента обрабатываются тем же контроллером. Декорации не дублируются
у приложений с собственными заголовками. Развёртывание учитывает свободную
область монитора и сохраняет обычный порядок наложения окон.

Рамки окон в stacking скрыты. Сворачивание сохраняет клиентский размер;
анимация уменьшает полное изображение до кнопки приложения. Восстановление
может развернуть уже начатую анимацию. Под наведением окна не получают фокус.
Панель задач группирует приложения; свёрнутые окна остаются в списке.
Закрепление и порядок хранятся в `~/.config/hyprstack/taskbar.json`.

**Alt+Tab** открывает переключатель с миниатюрами последних использованных
окон. Tab выбирает следующее, Shift+Tab — предыдущее; отпускание Alt активирует
выбор. Enter подтверждает, Esc отменяет. Свёрнутое окно восстанавливается.

## Нативный модуль

Модуль собирается из `native/hyprbars` под точный ABI текущего Hyprland.
Релиз не включает готовый `.so`: после обновления композитора нужна пересборка.
`HYPRSTACK_TITLEBAR_PLUGIN` задаёт путь для изолированных проверок; штатная
установка использует свой модуль из каталога данных Hyprstack.
Модуль не должен загружаться одновременно с обычным hyprbars.

Действия декораций передают адрес и стабильный идентификатор владельца;
контроллер проверяет их по текущему снимку композитора. Смена фокуса и повторное
использование адреса не перенаправляют действие на другое окно. Полная геометрия
меняется атомарно после пересчёта декораций. Нативное клиентское развёртывание
не запускает конкурирующий полноэкранный обработчик.

## Мониторы и сохранение настроек

`~/.config/hyprstack/workspaces.json` включает отдельные рабочие столы мониторов:

```json
{
  "per_monitor": true,
  "count": 10
}
```

Каждый экран показывает локальные номера 1–10; внутренние ID не пересекаются.
Перенос окон, цифровые сочетания и прокрутка сохраняют принадлежность монитору.
Для нового экрана выбирается свободный постоянный диапазон.

Режимы мониторов, масштаб, частоты, HDR, VRR и калибровка принадлежат локальной
конфигурации пользователя. Релизные комплекты не устанавливают настройки
конкретного компьютера и отдельные службы коррекции экранов.
