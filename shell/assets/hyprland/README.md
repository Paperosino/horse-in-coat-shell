# Размещение окон

Интеграция: `layouts.lua`, конфигурация `config/`, нативный модуль
`native/hyprbars`. Пользовательские параметры — в [CONFIGURATION.md](../../../CONFIGURATION.md).

**Super+Ctrl+Shift+M** переключает scrolling и stacking. При переходе в stacking
окна собираются на текущем рабочем столе своего монитора. Возврат восстанавливает
рабочие столы, порядок и ширину колонок. Размеры и положения плавающих окон
сохраняются отдельно.

## Scrolling

Новая колонка занимает половину ширины рабочей области, браузер — полную ширину.
**Super+Ctrl+F** переключает половинную и полную ширину. Фокус следует за курсором.
**Super+H/L** выбирает колонку или соседний монитор, **Super+J/K** — рабочий стол.

**Super+Alt+Space** переключает плавающее состояние. Диалоги, просмотрщики
Telegram/AyuGram и PiP остаются плавающими. Заголовки тайлов скрыты.

## Stacking

Фокус меняется по нажатию. Заголовки позволяют перемещать, сворачивать,
разворачивать и закрывать окна. Для переключения — **Alt+Tab**.
Порядок и закрепление приложений: `~/.config/hyprstack/taskbar.json`.

## Рабочие столы мониторов

Пример `~/.config/hyprstack/workspaces.json`:

```json
{
  "per_monitor": true,
  "count": 10
}
```

У каждого экрана свой диапазон рабочих столов с локальными номерами 1–10.
Настройки экранов задаются в `~/.config/hyprstack/monitors.lua`.

## Нативный модуль

Собирается под ABI Hyprland; после его изменения требуется пересборка.
Не загружайте одновременно обычный hyprbars.
