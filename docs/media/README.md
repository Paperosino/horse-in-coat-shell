# Демонстрация hics

Часть этих записей историческая и ещё содержит прежний брендинг Hyprstack.
Их нужно перезаписать на актуальной оболочке; текущее состояние проверки
описано в [статусе кампании](../RELIABILITY_STATUS.md).

| Файл | Содержимое |
| --- | --- |
| `showcase.gif` | Смена тем, stacking → tiling → stacking |
| `dashboard.gif` | Календарь, медиа и виджеты |
| `panel-tools.gif` | Актуальная запись hics 1.1.1-95: уведомление, история, закрытие по Escape |
| `customization.gif` | Прозрачность, тени и масштаб |
| `overview.gif` | Обзор окон |
| `trackpad-swipes.gif` | Жесты: колонки, рабочие столы и обзор |

Произведения на фоне:

- Кацусика Хокусай, «Большая волна в Канагаве» —
  [Art Institute of Chicago](https://www.artic.edu/artworks/24645).
- Винсент ван Гог, «Звёздная ночь» —
  [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Van_Gogh_-_Starry_Night_-_Google_Art_Project.jpg).
- Клод Моне, «Кувшинки» —
  [Art Institute of Chicago](https://www.artic.edu/artworks/16568).

Файлы этих обоев не входят в установку.
[Лицензии компонентов](../../THIRD_PARTY.md).

`panel-tools.gif` перезаписан на реальной CachyOS ВМ, русская локаль,
1280×800; происхождение и контрольные суммы — в `panel-tools.recording.json`.
Это запись интерфейса, не замер плавности на физическом GPU.
