# Демонстрация Hyprstack

Главный GIF в README показывает рабочий стол с lavat, Cava, cbonsai и pipes,
смену тем Kanagawa, Tokyo Night и Catppuccin Latte и переключение из stacking
в скроллинг-тайлинг и обратно. Переходы между темами смонтированы диагональной
шторкой; перемещения окон и переключения раскладки записаны в работающей оболочке.
Анимация длится 16,6 секунды, имеет разрешение 1024×576 и частоту 16 кадров в секунду.

Четыре GIF с отдельными панелями имеют разрешение 960×540, 20 кадров в секунду.
Все GIF зациклены и проигрываются прямо в README, без звука. Медиа не используются при запуске
или установке оболочки.

| Файл | Содержимое |
| --- | --- |
| `showcase.gif` | Смена тем, stacking → tiling → stacking · 16,6 с |
| `dashboard.gif` | Крупный план дашборда: календарь, медиа и виджеты · 8 с |
| `panel-tools.gif` | Центр уведомлений и быстрые действия панели · 6 с |
| `customization.gif` | Прозрачность, её результат на дашборде, тени и масштаб интерфейса · 9 с |

| `trackpad-swipes.gif` | Жесты: колонки, рабочие столы, обзор · 18 с · 960×600, 20 кадров/с |

В `panel-tools.gif` крупные планы двух панелей смонтированы рядом.
Остальные фрагменты показывают действия и изменения настроек в работающей оболочке.

Записи не содержат настроек конкретных экранов, терминала с личными путями,
системных характеристик или служебных материалов разработки.

В демонстрации показаны репродукции произведений:

- Кацусика Хокусай, «Большая волна в Канагаве» —
  [Art Institute of Chicago](https://www.artic.edu/artworks/24645).
- Винсент ван Гог, «Звёздная ночь» —
  [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Van_Gogh_-_Starry_Night_-_Google_Art_Project.jpg).
- Клод Моне, «Кувшинки» —
  [Art Institute of Chicago](https://www.artic.edu/artworks/16568).

Они служат фоном демонстрации. Отдельные файлы обоев не входят в исходники
или установленную оболочку. Авторство компонентов интерфейса указано в
[THIRD_PARTY.md](../../THIRD_PARTY.md).
