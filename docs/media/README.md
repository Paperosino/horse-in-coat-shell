# Демонстрация Hyprstack

Главный GIF в README показывает переход из stacking в скроллинг-тайлинг:
перекрывающиеся плавающие окна размещаются в колонках, панель меняет положение.
Анимация длится 7 секунд, имеет разрешение 1280×720 и частоту 20 кадров в секунду.

Ниже находятся четыре коротких GIF других возможностей. Каждая анимация
длится 5 секунд: разрешение 960×540, 12 кадров в секунду. Все GIF зациклены
и проигрываются прямо в README, без звука. Медиа не используются при запуске
или установке оболочки.

| Файл | Содержимое |
| --- | --- |
| `mode-switch.gif` | Переключение из stacking в tiling |
| `themes.gif` | Каталог тем и акцентов |
| `launcher.gif` | Поиск приложений |
| `notifications.gif` | Центр уведомлений |
| `controls.gif` | Быстрые действия |

Записи не содержат настроек конкретных экранов, терминала с личными путями,
системных характеристик или служебных материалов разработки.

В демонстрации показаны репродукции произведений:

- Кацусика Хокусай, «Большая волна в Канагаве» —
  [The Metropolitan Museum of Art](https://www.metmuseum.org/art/collection/search/45434).
- Винсент ван Гог, «Звёздная ночь» —
  [The Museum of Modern Art](https://www.moma.org/collection/works/79802).

Они служат фоном демонстрации. Отдельные файлы обоев не входят в исходники
или установленную оболочку. Авторство компонентов интерфейса указано в
[THIRD_PARTY.md](../../THIRD_PARTY.md).
