# Значки рабочего стола

Включаются в **Настройки → Персонализация → Кастомизация → Значки рабочего
стола**. По умолчанию функция выключена. Можно выбрать экран, размер значков,
сортировку, видимость скрытых файлов и открытие одним или двумя нажатиями.
Если выбранный экран отключён, используется первый подключённый.

Используется стандартная `XDG_DESKTOP_DIR` из `user-dirs.dirs`, включая
локализованные названия папок. Это те же файлы, которые показывают Nautilus,
Dolphin, Thunar, Nemo, Caja, PCManFM и другие файловые менеджеры. Отдельное
хранилище файлов или собственный файловый менеджер не создаются. Если XDG
отключает рабочий стол, указывая домашнюю папку, её содержимое не публикуется.

## Управление

- Нажатие выделяет файл; Ctrl позволяет выделить несколько; Ctrl+A — все.
- Enter открывает текущий файл, стрелки переключают выделение.
- Ctrl+C / Ctrl+X / Ctrl+V — копирование, вырезание и вставка. Используются
  URI-списки и форматы буфера GNOME/KDE.
- F2 — переименование; Delete — корзина с подтверждением; F5 — обновление.
- ПКМ по файлу или пустому месту — меню действий. Нажатие снаружи закрывает меню.
- Перетаскивание внутри рабочего стола переставляет значок по сетке. Положение
  сохраняется отдельно для каждого экрана. «Упорядочить значки» сбрасывает позиции.
- Перетаскивание из ФМ на пустую область **копирует** локальные файлы и папки.
  С рабочего стола в ФМ передаются стандартные URI и действия Copy/Move; дальнейшую
  операцию выполняет принимающий ФМ.

Открытие файла/архива/папки использует системные MIME-ассоциации через GIO.
«Показать в файловом менеджере» и «Свойства» используют D-Bus FileManager1;
если ФМ не предоставляет метод, открывается родительская папка в ФМ по умолчанию.
Полное меню расширений конкретного файлового менеджера остаётся в нём.
Корзина открывается в установленном ФМ, восстановление выполняется там.

## Надёжность и нагрузка

Список читает C++-провайдер в одном рабочем потоке. Используются уведомления
файловой системы с объединением событий; постоянного опроса и процессов `ls`
нет. Выключенная функция освобождает список и файловые наблюдения. В сцене
создаются только видимые значки с небольшим запасом. В холсте файлы остаются
привязаны к экрану; ввод направляется им только вне окон приложений. Средняя
кнопка и модификаторы сохраняют управление камерой. В режиме презентации
содержимое скрывается вместе с личными данными.

Копирование выполняет существующий `transfer.copy` в `hics-desktopd`: прогресс,
отмена и результат доступны в центре фоновых операций. Уже существующие файлы
не перезаписываются. Переименование, создание папок, корзина и локальные
перемещения используют GIO вне потока интерфейса. Корзина не подменяется
безвозвратным удалением; символическая ссылка удаляется сама, а не её цель.
После удачного вырезания буфер очищается только если пользователь не успел
заменить его содержимое.

Сложные перемещения между файловыми системами, виртуальные/сетевые источники
и копирование символических ссылок следует выполнять в установленном ФМ.
Фоновый копировщик сохраняет свои ограничения: до 128 источников, без обхода
символических ссылок. Частично завершённая операция не удаляет скопированные
данные при отмене. Существующие цели не заменяются молча.

Показ ограничен 2000 объектами с сообщением об ограничении; полное содержимое
всегда доступно в ФМ. Размер файла позиций ограничен 1 МиБ; координаты проверяются,
устаревшие имена удаляются из памяти. Пустой рабочий стол не заполняется домашними
файлами автоматически.

Файлы `.desktop` не запускаются автоматически. Для запуска ярлык должен быть
обычным файлом текущего пользователя с разрешённым выполнением. Непроверенный
ярлык предлагается открыть и разрешить через ФМ. Права существующих ярлыков
оболочка самовольно не меняет. Приложения запускаются в отдельных пользовательских
scopes, как и из меню оболочки.

Проверка: `python3 tests/integration_desktop_icons.py` создаёт отдельный HOME,
D-Bus и вложенный Hyprland. Проверяются события и отсутствие опроса в простое,
отключение функции, скрытые файлы, буфер, безопасные операции без перезаписи,
копирование папки через центр операций, перетаскивание значка и закрытие меню
настоящими событиями указателя. Пользовательские файлы не используются.

После обновления требуется новый графический сеанс для загрузки изменений
ввода внутри плагина холста. Перезапуск оболочки не выгружает плагин Hyprland.

Стандартные интерфейсы: [FileManager1](https://www.freedesktop.org/wiki/Specifications/file-manager-interface/),
[Qt Quick Drag](https://doc.qt.io/qt-6/qml-qtquick-drag.html),
[GIO File.move](https://docs.gtk.org/gio/method.File.move.html).

## Панели и контекстное меню

Сетка оставляет место для основной панели, дополнительных верхних и нижних панелей и дока. Отступы пересчитываются при изменении масштаба панели. ПКМ на свободном рабочем столе открывает настройки персонализации, экранов и панели; при включённых значках эти действия также доступны в файловом контекстном меню.
